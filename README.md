My Matplotlib Learning Path
This repo is just my personal notes and exercises as I learn Matplotlib from scratch, with the goal of getting comfortable enough to visualize data for ML/AI work later. It's not a tutorial, not a course, and definitely not a replacement for proper documentation or structured courses. I'm just tracking my progress in public.

What's in here
A few things I'm working on, roughly in this order:

Basics — plot, show, figures vs axes

Figure & Axes — subplots, add_subplot, layout control

Styling — labels, titles, legends, colors, linestyles

Plot types — line, scatter, bar, hist, imshow

Axes control — limits, ticks, scales (log, symlog)

Annotations — text, arrows, reference lines

Saving — savefig, DPI, formats
